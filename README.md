# A4 拼图打印台

把多张商品图片拖入网页工作台，自动生成接近参考图的 A4 三列联系表，并通过浏览器打印到本机打印机。

## 当前能力

- 一次拖入多张 JPG、PNG、WebP 图片
- 默认每页 9 张，三列三行，自动分页
- 可选每页 4、6、9、12 张
- A4 纵向或横向，白边和图片间距使用毫米
- “铺满”与“完整显示”两种适配方式
- 单张图片可拖动主体位置、缩放、旋转、移除
- 左侧每张缩略图带独立删除按钮，删除后自动重排和重新分页
- 支持 `Ctrl/⌘ + 点击`、`Shift + 点击`，以及在左侧缩略图列表按住鼠标滑动多选
- `Delete` / `Backspace` 可一次删除全部选中图片；捕获阶段监听兼容 `key`、`code`、`keyCode`
- 选中组的主图片右上角同时显示醒目的批量删除按钮
- 图片和版面设置保存在浏览器本机 `IndexedDB`，刷新或重新打开页面后自动恢复，不上传云端
- 根据原图像素和实际版面估算有效 DPI
- 在浏览器中生成固定版式的内嵌 A4 PDF
- PDF 预览支持浏览器自带的缩略图、连续页面、缩放、下载和打印
- 从内嵌 PDF 查看器选择本机打印机输出

## GitHub 在线部署

项目已经包含 GitHub Pages 自动发布工作流。代码推送到 `main` 分支后，GitHub 会自动执行测试、构建和部署。

首次发布只需在 GitHub 仓库中设置一次：

1. 打开仓库的 `Settings`。
2. 进入 `Pages`。
3. 在 `Build and deployment` 中把 `Source` 设为 `GitHub Actions`。
4. 打开 `Actions`，等待 `Deploy A4 Print Studio to GitHub Pages` 完成。

在线地址格式：

```text
https://你的GitHub用户名.github.io/a4-print-studio/
```

以后每次推送到 `main`，在线版本都会自动更新。图片和 PDF 都只在访问者浏览器本地处理，不会上传到 GitHub 或其他服务器。

## 打印准确性

- 默认保留 12mm 白边，兼容大多数非无边距打印机。
- Web 安全机制不允许网页枚举打印机或跳过系统打印窗口。生成 PDF 后，需要在 PDF 查看器的系统窗口选择打印机。
- 不同浏览器和打印机驱动可能再做一次缩放。请确认纸张为 A4、缩放为 100%，并关闭页眉和页脚。
- 低于 150 DPI 的图片会提示可能偏糊；商品图建议尽量达到 200-300 DPI。

## 架构说明

- Vite + React：纯 Web 拖拽工作台和版面参数控制
- jsPDF：在浏览器本地生成真实 A4 PDF，不上传商品图片
- PDF.js 内嵌查看器：跨浏览器提供缩略图、连续页面、缩放和逐页导航
- 原始 PDF Blob：提供下载，并交给浏览器系统打印
- 独立 `layout.js`：A4 几何、分页、模板和 DPI 计算，方便以后替换成更复杂的智能拼版算法
- CSS print media：屏幕工具栏不会进入打印内容，打印页使用真实毫米尺寸，支持本机打印和另存为 PDF
